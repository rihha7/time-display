# TimeDisplay

A simple Phoenix web application designed to display the current time in both analog and digital formats.</br>The digital clock displays the user's local time in either the standard 12-hour format or the 24-hour format. It also provides the name of the user's local time zone city and the current time period (AM/PM).</br>The application also includes a stopwatch and a timer utility.

## Requirements
- `Elixir`
- `Phoenix`
- `Erlang/OTP`

## Installation / Setup
- Clone the repository.
- Run `mix setup` to install and setup dependencies.
- Start Phoenix endpoint with `mix phx.server` or inside IEx with `iex -S mix phx.server`.

> Now you can visit [`localhost:4000`](http://localhost:4000) from your browser.

## Notes
- Switching between analog, 12-hour, and 24-hour clock formats reloads the page, resetting any active stopwatch or timer.
